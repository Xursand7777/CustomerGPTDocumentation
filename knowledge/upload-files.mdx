title: "Upload files"
description: "Train your chatbot on documents: text files in the dashboard, PDF and DOCX after a quick conversion or with the CLI."
---

| Format | Dashboard | CLI |
| --- | --- | --- |
| `.txt` | Yes | Yes |
| `.md`, `.csv` | Yes, by drag and drop | Yes |
| `.pdf`, `.docx` | Convert first, see below | Yes |

Files can be up to 10 MB each.

## Upload in the dashboard

1. Select your chatbot and open **Knowledge Base**.
2. Drag a file onto the upload area, or click **Browse Files**. Upload one file at a time.
3. The file appears under **Trained Knowledge Sources**. Text files are ready as soon as they show **completed**.

<Warning>
  Don't upload PDF or DOCX files in the dashboard for now: it doesn't extract their text yet, so the chatbot doesn't learn your document. Use one of the options below.

  If you already uploaded a PDF there, delete that source with `customergpt knowledge documents delete`, or ask [support@customergpt.ai](mailto:support@customergpt.ai) to remove it.
</Warning>

## PDF and DOCX files

<Tabs>
  <Tab title="Convert, then upload (any plan)">
    1. Open the free [PDF to Markdown](https://customergpt.ai/tools/pdf-to-markdown) or [DOCX to Markdown](https://customergpt.ai/tools/docx-to-markdown) converter.
    2. Upload your file, click **Convert to Markdown**, and download the result as a `.md` file.
    3. Drag the `.md` file onto the upload area in **Knowledge Base**.
  </Tab>
  <Tab title="CLI (Growth and above)">
    The server extracts the text for you:

    ```bash
    customergpt knowledge files add ./handbook.pdf --chatbot BOT_ID --yes --wait
    ```

    Each file trains on up to 50,000 characters, and the CLI warns you if it cut anything off. Split longer documents into parts.
  </Tab>
</Tabs>

## What gets read

- **Text only.** Images and charts are skipped. Scanned PDFs have no text layer, so run them through OCR first.
- **Tables become plain text.** Keep important tables simple, or upload them as a `.csv` file.

To replace a file with a newer version, delete the old source and upload the new one. See [Keep your content up to date](/knowledge/keep-content-up-to-date).
