title: "Upload files"
description: "Train your chatbot on PDF, Word, text, Markdown and CSV files from the dashboard or the CLI."
---

| Format | Dashboard | CLI |
| --- | --- | --- |
| `.pdf` | Yes | Yes |
| `.docx` | Yes | Yes |
| `.txt`, `.md`, `.csv` | Yes | Yes |

Files can be up to 10 MB each. Save older `.doc` files and presentations as `.docx` or PDF first.

## Upload in the dashboard

1. Select your chatbot and open **Knowledge Base**.
2. Drag a file onto the upload area, or click **Browse Files**. Upload one file at a time.
3. Wait while the dashboard reads the text and trains your chatbot on it. Large files can take a minute.
4. The file appears under **Trained Knowledge Sources** as **completed**, and the chatbot can answer from it right away.

If a file can't be used, the dashboard tells you why and adds nothing:

- **No text found in the PDF**: the PDF is a scan. Run it through OCR, then upload it again.
- **That PDF could not be read**: the PDF is password-protected. Remove the password, then upload it again.
- **File too large**: the file is over 10 MB. Split it into parts.
- **Data Ingestion blocked**: the file would take you over your plan's page limit. See [How much you can train](/knowledge/add-your-website#how-much-you-can-train).

<Note>
  Before October 2026, the dashboard didn't read PDF files and trained on a placeholder instead of your document. Those placeholder sources have been removed. If you uploaded a PDF in the dashboard before then, upload it again.
</Note>

## Upload with the CLI

The CLI needs a plan with API access (Growth and above):

```bash
customergpt knowledge files add ./handbook.pdf --chatbot BOT_ID --yes --wait
```

Each file trains on up to 50,000 characters through the CLI, and the CLI warns you if it cut anything off. Split longer documents into parts, or upload them in the dashboard.

## What gets read

- **Text only.** Images and charts are skipped. Scanned PDFs have no text layer, so run them through OCR first.
- **Tables become plain text.** Keep important tables simple, or upload them as a `.csv` file.

To replace a file with a newer version, delete the old source and upload the new one. See [Keep your content up to date](/knowledge/keep-content-up-to-date).
