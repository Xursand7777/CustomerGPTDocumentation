---
title: "Get a chatbot"
api: "GET /v1/chatbots/{id}"
description: "Read one chatbot's settings."
---

import ChatbotFields from '/snippets/chatbot-fields.mdx';

<ParamField path="id" type="string" required>
  The chatbot's `id`, not its `widgetId`.
</ParamField>

A chatbot that isn't in your workspace returns 404.
