import ChatbotFields from '/snippets/chatbot-fields.mdx';

<ParamField body="name" type="string" required>
  The name visitors see in the chat window. Up to 100 characters.
</ParamField>
<ParamField body="websiteUrl" type="string" required>
  The site the widget will load on, with `https://`. The widget works on this domain and its subdomains only.
</ParamField>
<ParamField body="welcomeMessage" type="string">
  The first message in the chat. Up to 500 characters.
</ParamField>
<ParamField body="primaryColor" type="string">
  The widget's main color, as a hex code such as `#224CFF`.
</ParamField>
<ParamField body="quickPrompts" type="string[]">
  Suggested questions shown before the first message.
</ParamField>

Returns 201 with the new chatbot. Returns 400 if the input is invalid, or if your plan's chatbot limit is reached.

To train the chatbot, add a source with the [`sources_add`](/api-reference/knowledge/add-knowledge-source) action, the [CLI](/cli/overview), or the dashboard.
