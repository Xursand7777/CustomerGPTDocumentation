## Before you start

- **A plan with API access.** The API, SDK, CLI and MCP server need the Growth, Scale or Enterprise plan. Webhooks need Scale or Enterprise.
- **An API key, or a sign-in.** Create a key under **Role Permissions → Public API Keys** in the dashboard; see [Authentication](/api-reference/authentication). The CLI and the MCP server can sign you in through the browser instead.

## Try it without an account

The onboarding actions build a temporary demo chatbot from a website, without an account or a key. The demo lasts 24 hours and answers up to 20 preview messages. You can then claim it into your workspace.

```bash
npx @customergpt/cli onboarding start https://acme.com --yes --wait
```

## Build with an AI coding agent

- `customergpt agent-guide` prints the workflow and command map for AI agents.
- The CLI's agent skill, which teaches Claude Code, Codex, Cursor and others to build a support bot, is at `https://api.customergpt.ai/agents/customergpt-cli-skill.md`.
- This documentation is available as plain text for AI tools at [/docs/llms.txt](https://customergpt.ai/docs/llms.txt).
